# 拾图：截图资料库

一个可以加到 iPhone 主屏幕的离线网页应用。第一版不需要账号、服务器或 App Store，图片和资料只存放在当前设备的浏览器中。

## 已有功能

- 多选导入截图
- 按分类、标签、标题和备注搜索
- 自动识别截图里的简体中文和英文文字，并参与搜索
- 新建分类、编辑资料、删除截图
- 离线打开（首次访问后）
- PWA 清单和图标：可“添加到主屏幕”
- 一键备份为 `.json` 文件，或从该文件合并恢复
- 显示当前浏览器实际的已用与预计可用空间（设备支持时）

## 本地运行

```bash
npm run vault:dev
```

手机和电脑连同一 Wi-Fi 后，打开终端显示的 Network 地址。iPhone 用 Safari 打开，再选择“分享” → “添加到主屏幕”。

生产构建：

```bash
npm run vault:build
```

构建产物位于 `dist/screenshot-vault/`。

## 免费部署

本仓库内置 GitHub Pages 工作流。推送到 `main` 分支后，GitHub 仓库的 **Settings → Pages** 里将发布源设为 **GitHub Actions**；首次发布完成后，网站会出现在仓库的 Pages 链接。

## 隐私与边界

数据使用 IndexedDB 保存在当前浏览器配置文件中，清除 Safari 网站数据或换设备会一并清除。请定期使用“备份到文件”，并把下载的 `.json` 文件保存到“文件”App 的 iCloud Drive 或其他可靠位置；恢复操作只会合并新截图，不会删除当前内容。OCR 引擎与语言包随网站部署，识别在浏览器本机进行，截图不会上传。请勿使用 Safari 无痕浏览或会话模式导入图片：这些模式会在会话结束时清除网页资料。当前的搜索可检索截图文字、文件名生成的标题、分类、标签和备注。
