The files in this directory are bundled so screenshot OCR can run locally in the browser.

- `tesseract.min.js` and `worker.min.js` are from [Tesseract.js 5.1.1](https://github.com/naptha/tesseract.js), licensed under Apache-2.0.
- `core/` is from [tesseract.js-core 5.1.1](https://github.com/naptha/tesseract.js-core), licensed under Apache-2.0.
- `lang/` contains the `chi_sim` and `eng` fast language data from the Tesseract project, which is licensed under Apache-2.0.

These are OCR engine and language-model assets only. No user screenshots or personal data are included in this repository.
